## 0.1.0

- Initial release of `flutter_scenario_recorder`.
- Declarative scenario DSL (`ScenarioStep`, `ScenarioTargetMatcher`, `HighlightStyle`).
- Overlay stage (`ScenarioStage`) with pulse border, elevation glow, spotlight dimming, and virtual touch pointer with ripple animation.
- Deterministic frame-accurate MP4 video rendering (`FfmpegPipeFrameRecorder`, `DeterministicVideoScenarioClock`, `ScenarioHeadlessHarness`).
- CLI runner (`dart run flutter_scenario_recorder:render_video`) enabling native macOS `Apple Color Emoji` and clean layout rendering.
- Included Cursor Agent Skill (`skills/flutter-scenario-video/SKILL.md`).
